### Release state

Only the previous Cloudflare Worker serves the public TaskService domain. The V2 code runs separately in verification environments. The Publisher VPS, routing, running containers, application databases and store integrations were untouched. A separate Publisher branch contains only the isolated prerequisite audit workflow. The read-only audit script is prepared for an authenticated Publisher SSH session via an approved channel. In a future release, current measurements and a verified backup must precede any cutover.

### Design revision evidence

The official D1 export restored with three requests, two attachments and zero messages. The import rehearsed against disposable PostgreSQL with real RLS roles and verified rollback, exact replay without duplicates, tenant separation, no automatic ownership assignment and quarantine for both files. [Import operations](../ops/README.md#d1-snapshot-rehearsal) describe applying a final snapshot after ownership and cutover approval. No import has run on Publisher.

The [visual regression checklist](visual-regression.md) records the comparisons and manual review. Main's Worker and its D1 bindings remain untouched. The C# intake accepts the original service categories, contact data and up to three photo attachments. PostgreSQL quarantines new request photos, the existing scanner checks them, and authorized downloads enforce the same request and tenant access boundaries. See the [photo inventory](design-assets.md).

The edge middleware accepts forwarded transport and client IP only from explicitly listed proxy IPs. Host forwarding is disabled. Unit verification covers spoofed headers from an untrusted node. See the README for deployment configuration and verification prerequisites.
