### Release state

Only the previous Cloudflare Worker serves the public TaskService domain. The V2 code runs separately in verification environments. Neither Publisher nor its routing, containers, workflows, databases or store integrations were modified. The read-only audit script is prepared for an authenticated Publisher SSH session via an approved channel. In a future release, current measurements and a verified backup must precede any cutover.
